# Manual do Usuário - MK9 Analytics

## 1. Introdução
O MK9 Analytics é o centro operacional para gestão de campo. Este manual orienta cada perfil de usuário sobre como utilizar as funcionalidades do sistema.

## 2. Guia para Administradores
### Importação de Checklists
1. Acesse o módulo **Importador**.
2. Selecione a **Indústria** e a **Competência** (Mês/Ano).
3. Faça o upload do arquivo Excel.
4. Revise os alertas de **Qualidade** (lojas novas, frequências alteradas).
5. Clique em **Confirmar Importação** para processar os dados.

### Limpeza Manual
- Utilize esta função apenas para corrigir erros graves de importação.
- O sistema registrará quem executou a limpeza e o estado dos dados antes e depois.

---

## 3. Guia para Supervisores
### Dashboard e Relatórios
- **Visão Geral**: Acompanhe o percentual de execução em tempo real.
- **Auditoria PDF**: Gere relatórios consolidados por indústria para envio aos clientes.
- **Cockpit**: Identifique rapidamente lojas com baixa performance ou falta de visitas.

### Gestão de Roteiros
- Visualize a distribuição das visitas planejadas versus realizadas por promotor e por loja.

---

## 4. Guia para Promotores
### Registro de Visitas
- O sistema processa automaticamente as visitas importadas via checklist.
- Certifique-se de que os dados no Excel (Nomes de Lojas, Datas) seguem o padrão estabelecido para evitar inconsistências.

---

## 5. Fluxo Operacional Diário
1. **Manhã**: Supervisores revisam o Cockpit para identificar prioridades.
2. **Durante o Dia**: Importação de novos checklists conforme recebimento.
3. **Fim do Ciclo**: Geração dos PDFs de auditoria para fechamento de competência.
